# Facebook Clone Website

This project is a **Facebook website clone** that I created as part of my journey to learn and practice **Git and GitHub**. The main purpose of this project was to understand how to create a basic web project, manage files using Git, and upload and maintain the project using GitHub.

## 📌 About the Project

The website is inspired by the basic layout and design of Facebook. It recreates some of the common elements found on a social media platform, such as a navigation bar, user profile section, posts, and other interface components.

This project was mainly created for **learning and practice purposes** and is not intended to be an exact copy of the original Facebook website.

## 🎯 Purpose of the Project

The main goals of creating this project were:

* To practice basic web development concepts.
* To understand how Git works for version control.
* To learn how to create and manage a GitHub repository.
* To practice adding, committing, and tracking changes using Git.
* To understand how a website project can be organized into different files.
* To gain hands-on experience by building a project based on a familiar website interface.

## 🛠️ Technologies Used

* **HTML** – Used to create the structure of the website.
* **CSS** – Used for styling and designing the user interface.
* **Git** – Used for version control and tracking project changes.
* **GitHub** – Used to store and manage the project repository.

## ✨ Features

Some of the main UI elements included in this project are:

* Facebook-inspired navigation bar
* User profile section
* Social media post layout
* Sidebar/navigation elements
* Basic responsive styling
* Simple and familiar social media interface

## 📚 What I Learned

While working on this project, I learned the basics of using **Git and GitHub**, including:

* Creating a Git repository
* Initializing Git in a project
* Adding files to the staging area
* Creating commits
* Tracking changes
* Connecting a local project to GitHub
* Pushing code to a remote repository
* Managing a project through GitHub

This project helped me understand how version control can be used while developing and maintaining software projects.
